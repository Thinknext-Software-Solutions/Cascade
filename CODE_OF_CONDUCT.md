# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1.

## TL;DR

- Be respectful and constructive.
- Critique ideas, not people.
- No harassment, discrimination, or personal attacks.
- Disagreement is healthy; rudeness is not.

## Enforcement

Report violations to **conduct@thinknextsoftware.com**. Reports are reviewed by maintainers and handled confidentially. Consequences range from a private warning to a permanent ban.

## Scope

Applies to all project spaces — GitHub, Discussions, social channels, and anyone representing the project publicly.
