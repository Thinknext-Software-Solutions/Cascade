# Constraints

> Non-functional requirements that affect how new work should be designed and built.

## Performance

- API response time targets (e.g., p99 < 200ms)
- Database query budgets (e.g., < 5 queries per request)
- Memory limits, payload sizes, etc.

## Security

- Authentication requirements
- Data handling (PII, encryption, audit logging)
- Compliance regimes (SOC 2, HIPAA, GDPR, etc.)

## Deployment

- Runtime environment (containers, serverless, etc.)
- Deployment frequency expectations
- Rollback constraints

## Compatibility

- Supported browsers / OS / runtime versions
- API versioning rules
