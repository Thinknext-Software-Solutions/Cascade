# Glossary

> Domain-specific terms used in this codebase. Cascade reads this so AI-generated names, comments, and docs match your team's vocabulary.

## Format

```
**Term**: definition. When/where it's used. What it is NOT.
```

## Example

**Workspace**: A user's top-level container. Each user can have multiple workspaces. Equivalent to what other products call a "project" or "tenant." NOT a folder, NOT a UI panel.

**Run**: A single execution of a workflow. Has a start time, end time, status, and produces artifacts. NOT the same as a "job" (a job has many runs over time).
